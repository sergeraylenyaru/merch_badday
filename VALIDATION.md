# Проверка первой версии

Проверено в облачной Linux-среде: Node.js 24.19.0, npm 11.9.0, системный Chromium, программный WebGL через SwiftShader.

## Выполнено

- `npm ci --cache /tmp/npm-cache --no-audit --no-fund` — чистая установка из lockfile успешна.
- `npm test` — 4 теста, 4 успешных, 0 пропущенных. Проверены обязательные условия всех восьми магазинов, однократная выплата наград, частичный маршрут, розыск, сериализация и восстановление состояния.
- `npm run build` — production-сборка успешна. Vite предупреждает о JS-файле больше 500 КБ: он содержит Three.js и Rapier с WASM. Примерно 2,77 МБ без сжатия, 0,97 МБ gzip. Это предупреждение, не ошибка сборки.
- `npm run test:e2e` — браузерный сценарий успешен: физическая доставка тележки и счётчик 2/2; бейдж и полное закрытие первого магазина; посадка, реальное перемещение машины и выход; подтверждённый маршрут после перезагрузки; правильная выкладка; создание снимка сцены и принятие фотоотчёта; удар, рост розыска и итоговый экран. Неперехваченных ошибок JavaScript нет.
- Отдельная проверка: стартовое меню, видимая 3D-сцена, движение пешком, карта телефона, пауза и восстановление позиции после перезагрузки.
- HTTP-запрос к запущенному Vite — ответ 200.

## Повторить браузерную проверку

```sh
npm run test:e2e
```

Сценарий сам запускает отдельный Vite на порту 5188 и завершает его после проверки. Использует `/usr/bin/chromium`, если он установлен, либо браузер Playwright. Можно задать `BROWSER_PATH=/путь/к/chromium npm run test:e2e`. Если браузера нет, установите его штатным способом или `npx playwright install chromium` при разрешённом доступе к CDN Playwright. В этой среде CDN вернул 403; проверка успешно выполнена системным Chromium, без отключения проверки сертификатов или целостности.

Браузерные сценарии используют подготовленные сохранения для размещения игрока и объектов около проверяемой системы. Само прохождение, перенос тележки, разговор, езда и мини-игры выполняются обычным вводом клавиатуры и мыши; тест не вызывает внутренние функции завершения задания.

## Не подтверждено

Полное непрерывное прохождение всех восьми магазинов за 25 минут, длительный нагрузочный прогон, все виды транспорта и доставка в кузове, надёжный объезд всех зданий полицией и конкурентом, все возможные концовки в браузере, работа на всех интегрированных GPU и восстановление в новой опубликованной облачной задаче. Условия восьми визитов проверены логическими тестами. Ограничения физики и AI перечислены в README.

Скрипт установки и инструкции запуска сохранены в черновике настроек облачной среды. Публикация пользователем — отдельный шаг; сохранение черновика не означает публикацию.

## Подготовка веб-публикации

Production-сборка проверена в Chromium как статический сайт по вложенному пути `/merch_badday/`: стартовая сцена, начало смены и карта телефона работают; неудачных HTTP-загрузок ресурсов и ошибок JavaScript нет. Для GitHub Pages применён относительный `base`. Готовая версия экспортируется командой `npm run build:pages` в корень `main`; исходный HTML перенесён в `src/index.html` и обслуживается Vite. Репозиторий и workflow отправлены на GitHub.
