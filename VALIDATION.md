# Проверка визуального обновления

Проверено 27 октября 2026 в облачной Linux-среде: Node.js 24.19.0, npm 11.9.0, Chromium 154.0.8037.57, WebGL 2 через программный SwiftShader.

## Результаты

- `npm ci --cache /tmp/npm-cache --no-audit --no-fund` — установка по существующему lockfile успешна. Зависимости и lockfile не изменены.
- `npm test` — **10 успешных, 0 пропущенных, 0 ошибок**: четыре прежних теста маршрута/сохранения, пять тестов кеширования GLB, нормализации размеров, ошибки загрузки, независимости скелетов и однократного освобождения общих ресурсов, а также проверка экспорта GLB и лицензий в корень сайта Pages.
- `npm run build` — успешная production-сборка. JS около 2,89 МБ, gzip 1,01 МБ; предупреждение Vite о chunk больше 500 КБ сохраняется. Оно не отключалось и не является ошибкой сборки.
- `npm run test:e2e` — прежний игровой сценарий прошёл без изменения теста: физическая доставка тележки и 2/2, бейдж и подтверждение первого визита, посадка/движение/выход из машины, сохранение после перезагрузки, выкладка, фотоотчёт, бой/розыск и итоговый экран. Неперехваченных ошибок JavaScript нет.
- `node tests/visuals.e2e.mjs` — успешная визуальная проверка. Все **14 GLB** загружены локально, каждый URL запрошен один раз. Подтверждены семь замен видимых объектов, габариты и нижняя точка моделей, непустая сцена, движение и опора героя, обе камеры, оба режима качества, восстановление положения, дождливая сцена и отсутствие неожиданных ошибок браузера.
- В том же сценарии герой упирается в прежнюю заднюю стену магазина. Автомобиль с новой GLB-моделью проезжает из Z=25 и останавливается у той же стены на Z≈14,226; исходная логика столкновения сохранена.
- После трёх циклов телефона/паузы GPU-счётчики остались **542 геометрии и 48 текстур**, число живых GLB-экземпляров не выросло. Это ограниченный smoke-тест стабильности ресурсов, а не многочасовой тест памяти.
- При намеренно прерванной загрузке `shopping-cart.glb` игра запускается с запасными тележками: 13 моделей загружены, одна ошибка обработана, работает взятие/отпускание тележки и движение. Ожидаемое предупреждение загрузчика отделено от неожиданных ошибок.
- Production-сборка проверена браузером по вложенному пути `/merch_badday/`: все 14 GLB отвечают HTTP 200 по этому пути, начало смены и карта телефона работают, ошибок JavaScript и ресурсов нет. Эта локальная проверка сборки сама по себе не подтверждает завершение развёртывания GitHub Pages.

## Снимки фактически запущенной игры

Файлы создаются в игнорируемой папке `.playwright/`:

- `visual-district-intro.png` — стартовый вид первого района.
- `visual-district-play.png` — игровой вид и модель героя.
- `visual-district-rain.png` — дождливая сцена.

Первые три снимка воспроизводятся командой `node tests/visuals.e2e.mjs`.

## Повторить проверки

```sh
npm ci --cache /tmp/npm-cache --no-audit --no-fund
npm test
npm run build
npm run test:e2e
node tests/visuals.e2e.mjs
```

Браузерные сценарии сами запускают и завершают Vite на портах 5188 и 5190 соответственно. Используется `/usr/bin/chromium`, при необходимости путь задаётся через `BROWSER_PATH`. Они применяют тестовые сохранения, но действия выполняют обычным вводом, без вызова внутренних функций завершения заданий. Внутренняя диагностика `__MERCH__` доступна только для чтения.

Для разработки: `npm run dev -- --port 5173 --strictPort`. Для проверки сборки по вложенному пути: `npm run preview -- --host 127.0.0.1 --port 4173 --strictPort --base /merch_badday/`. Эти адреса используются для локальной проверки, не как опубликованные web-preview.

## Производительность и границы проверки

В экономном режиме отключены динамические тени и выборка PMREM-отражений, коэффициент разрешения — 0,85. Отражения вычисляются один раз и используются в высоком качестве. Товары и архитектура объединены по материалам; повторяющиеся уличные модели используют InstancedMesh. Декоративные прутья тележек и товары не имеют отдельных физических тел.

Конкретный FPS на офисном компьютере, длительный нагрузочный прогон, все интегрированные GPU, непрерывное прохождение восьми магазинов и все концовки браузером не проверены. Первый район оформлен полностью в выбранном стиле; остальные семь магазинов и остальные типы транспорта сохраняют прежние модели. Прежние ограничения AI и аркадной физики перечислены в README.

Исходные правила заданий, формат сохранений, управление и существующие игровые тесты сохранены. Лицензии и происхождение моделей — в [ASSET_SOURCES.md](ASSET_SOURCES.md), устройство обновления и порядок расширения — в [VISUAL_UPGRADE.md](VISUAL_UPGRADE.md).

Инструкции установки и запуска сохранены в черновике облачной среды. Сохранение черновика не означает публикацию; восстановление новой опубликованной задачи не проверено.
