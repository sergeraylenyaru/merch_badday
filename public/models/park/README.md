# Аттракционы проекта

Оригинальная геометрия и анимации, созданные для merch_badday:
цепочная карусель, качающийся корабль, мини-американские горки.

Источник: `src/visuals/park-models.js`.
Воспроизведение: `node scripts/create-park-models.mjs`.
Статические части объединены по материалам; подвижные узлы и анимации
сохранены в GLB. Сторонних текстур и декодеров нет.
