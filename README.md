# Плохой день мерча

**[▶ Играть в браузере](https://sergeraylenyaru.github.io/merch_badday/)** — GitHub Pages, без установки. Для управления нужны клавиатура и мышь.

Играбельная первая версия браузерной 3D-песочницы про рабочий маршрут мерчендайзера. Все модели процедурные, шрифты поставляются локально; коммерческих игровых ассетов нет.

## Запуск

Нужны Node.js 22.12+ (проверено на 24.19) и современный настольный браузер с WebGL 2.

```sh
npm ci
npm run dev
```

Откройте адрес, который напечатает Vite. Для сборки: `npm run build`; для проверки сборки: `npm run preview`. База данных, сервер API и секреты не требуются. После установки npm-зависимостей игра не обращается к внешним сервисам. Для звука нужно начать смену нажатием кнопки.

## Публикация на GitHub Pages

Репозиторий содержит workflow `.github/workflows/pages.yml`: каждый push в `main` проверяет проект, собирает игру и публикует `dist` через GitHub Pages. Если Pages ещё не включён, в **Settings → Pages → Build and deployment → Source** выберите **GitHub Actions**, затем запустите workflow **Publish game to GitHub Pages** во вкладке **Actions** (Run workflow) или отправьте новый коммит в `main`.

Адрес игры: `https://sergeraylenyaru.github.io/merch_badday/`. Первая публикация занимает несколько минут. В `vite.config.js` используется относительный `base`, поэтому графика, WASM и шрифты работают внутри пути репозитория. Папку `dist` также можно выложить на любой статический HTTPS-хостинг. Открывать исходный `index.html` прямо через `file://` не нужно: браузеру требуется собранная версия и HTTP(S).

## Как играть

Смена длится 25 минут активного игрового времени. Меню, телефон и диалоги приостанавливают мир. Возле первого магазина есть машина, две тележки и сотрудник Нина.

1. Подойдите к тележке, нажмите R, приведите её в жёлтую зону слева от входа и отпустите R. Верните обе тележки.
2. Подойдите к сотруднику внутри, нажмите E, покажите бейдж. Снова поговорите и вежливо попросите подтвердить визит.
3. Выберите следующую точку в телефоне. В других магазинах требуются выкладка на правой полке или фотоотчёт из телефона у собранных тележек.
4. Закройте восемь точек или завершите день через паузу. Итог зависит от работы, репутации, конфликтов и розыска.

| Клавиша     | Действие                                                                 |
| ----------- | ------------------------------------------------------------------------ |
| WASD        | Ходить / газ, задний ход, руль                                           |
| Shift       | Бег / ручной тормоз                                                      |
| Space       | Прыжок / тормоз                                                          |
| Ctrl        | Присесть                                                                 |
| E           | Сотрудник, полка, кофе; сесть / выйти                                    |
| R           | Взять / отпустить тележку; загрузить / выгрузить в фургоне или грузовике |
| F / ЛКМ     | Удар                                                                     |
| G / Q       | Сильный удар / блок                                                      |
| M / Tab     | Телефон / карта                                                          |
| C           | Первое / третье лицо                                                     |
| Esc         | Пауза, настройки и освобождение курсора                                  |
| Мышь        | Обзор после щелчка по игровой сцене                                      |
| Стрелки ← → | Альтернативное вращение камеры без захвата мыши                          |

В настройках можно изменить чувствительность, громкость и качество. На слабых устройствах качество автоматически снижается. Кофе около магазинов восстанавливает здоровье и снижает стресс за 40 ₽. Энергетик покупается в телефоне. За пределами кварталов есть тайники. Агрессия и опасное вождение вызывают жалобы, преследование, штрафы и потерю времени. Прятаться нужно дальше 30 м от полицейских и не нарушать правила.

## Реализовано

- Связный город, дороги, здания, остановка, деревья, восемь открытых торговых зон и сотрудники.
- Ходьба, бег, прыжок, приседание, две камеры и процедурные движения персонажей.
- Rapier: физические тележки, столкновения с землёй, стенами, персонажем и друг другом; перенос, толкание и доставка.
- Четыре типа управляемых машин с разными характеристиками, движение фонового транспорта, загрузка тележек в грузовой транспорт.
- Маршрут с восемью визитами, диалоги, бейдж, репутация, обмен помощью за деньги, мини-игра выкладки и настоящая фотография кадра.
- Здоровье, стресс, кофе, энергетик, тайники, конкурент, рабочие сообщения, дождь и смена дневного освещения.
- Удары, сильный удар, блок, оглушение, свидетели, реакции сотрудников, розыск 0–5, полицейские пешком и патрульные машины при высоком розыске, задержание.
- Телефон с пятью вкладками, карта и мини-карта, результаты смены, несколько исходов.
- Автосохранение каждые 5 игровых секунд и при открытии меню / уходе со страницы. Сохраняются маршрут, положение, машины, тележки и последствия. Новая смена удаляет текущее сохранение после подтверждения.

## Структура

- `src/main.js` — игровой цикл, управление, камера, транспорт, AI, бой, полиция, звук, погода и соединение систем.
- `src/world.js` — процедурные сущности, город, Rapier и геометрические проверки столкновений.
- `src/state.js` — данные магазинов, состояние, условия заданий, награды, окончания, сохранение.
- `src/ui.js`, `src/style.css` — меню, HUD, телефон, диалоги, выкладка и результаты.
- `tests/state.test.js` — проверки условий маршрута, наград, исходов и сохранения.

## Проверки

`npm test` выполняет логические тесты, `npm run build` создаёт production-сборку. Функциональные браузерные проверки и их результаты описаны в `VALIDATION.md`.

## Известные ограничения первой версии

Это компактная low-poly демоверсия, а не полноразмерный городской симулятор. Машины используют аркадное движение и геометрическое разрешение столкновений; полноценная динамика Rapier применяется к тележкам. Повреждений кузова и ragdoll нет. AI использует локальное движение без дорожного графа: полиция и конкурент могут застревать за зданиями, а фоновый транспорт движется по одной магистрали. Разговоры и магазины используют общую систему с тремя дополнительными условиями, а не восемь отдельных сюжетных кампаний. Лицевой анимации, полноценной музыки, переназначения клавиш и мобильного управления нет. Погода и освещение упрощённые; ночь после смены не симулируется. В памяти сохраняется только последняя смена; фотографии показываются до закрытия телефона и не записываются в localStorage. Концовки выбираются по приоритету условий; идеальный полный маршрут даёт «Звезда торгового зала», сбор всех тележек без закрытия всех визитов — «Король тележек». Сохранения относятся к текущему браузеру и адресу сайта.

Следующие улучшения: дорожный граф и обход препятствий для AI, отдельный модуль транспорта с физическим шасси, сценарии восьми магазинов, скелетная анимация, оптимизация геометрии инстансингом и дополнительное автоматическое прохождение маршрута целиком.
