# Открытая бета: город и начало рабочего дня

Новая смена начинается у жилого дома. После нажатия «Выйти на маршрут»
поступает звонок регионального менеджера. Ответьте, возьмите отмеченную машину
рядом с домом и отправляйтесь к первому магазину «У дома».

1. Полностью поставьте легковую машину в голубую разметку и остановитесь.
2. Выйдите и оплатите 40 ₽ в паркомате.
3. Найдите Нину в зале и возьмите задание через рабочий диалог.
4. Восстановите три секции — чай, сок и крупу. Подойдите к каждой отметке
   и нажмите E; дождитесь завершения действия.
5. Вернитесь к Нине и попросите подтвердить визит.

Парковка сама по себе больше не закрывает первый магазин. Принятый звонок,
оплата, принятое задание и отдельные секции сохраняются. Завершённые визиты
из старых сохранений сохраняются; для нового начала используйте «Новая смена».

## Город

У земли теперь единый рельеф с руслами и береговыми склонами. Вода — одна
непрерывная поверхность на 0,45 м ниже земли. Соседние куски водоёма
не расходятся, плиточная сетка убрана. Пляж и набережная следуют берегу.

Все дорожные сегменты связаны в одну сеть. Соединены подходы к кольцу,
северная улица, дорожки парка и восточные подходы. Мостовые пролёты подняты
на 0,55 м; подъезды имеют плавный уклон, по сторонам стоят перила.
Графика, высота персонажей и машин и коллизии Rapier используют один профиль
дорог: поверх воды есть физическое полотно, а не только изображение.

## Люди

В каждом из девяти магазинов к управляющему добавлены два сотрудника зала.
Они обходят зал, останавливаются возле игрока и дают подсказки по E.
Сотрудники не подтверждают визит вместо управляющего.

Три пеших полицейских используют отдельную модель Quaternius Swat, CC0-1.0,
с 18 записанными анимациями. Происхождение и воспроизводимая адаптация описаны
в `art/quaternius/README.md`; сборка — `scripts/import-police.py`.
Модель и анимации поставляются локально.

## Проверка и выпуск

`npm ci`, `npm test`, `npm run build`, `npm run test:e2e`.
Основной браузерный тест проверяет реальную новую смену, звонок, доступ к машине,
поездку, парковку, выдачу задания, три секции, подтверждение и сохранение,
состав сотрудников и полицейских и движение по двум основным мостам.
Браузерные проверки требуют Chromium и запускаются последовательно.

`npm run build:pages` обновляет статические файлы в корне для GitHub Pages.
`node tests/beta-pages.e2e.mjs` проверяет экспорт по пути `/merch_badday/`,
включая звонок, WebGL, карту и загрузку полицейской модели без HTTP-ошибок.
Публикация происходит после коммита/отправки изменений выбранным владельцем
репозитория способом. Изменения в рабочей среде сами по себе сайт не обновляют.

Ограничения беты: управление рассчитано на настольный браузер с WebGL 2,
машины используют аркадную физику, пешеходы — локальное движение.
Это обновление не добавляет мобильное управление, сетевой режим или полноценный
поиск пути для всего городского трафика.
